# India Air Pollution Tracker

Pollution types across 50 Indian cities (Aug 2022 to Oct 2026) found with K-means. Map, city pages, wind and a day classifier.

Tanmay Gautam, 24151020. DEC 351 Fundamentals of AI/ML.

Data: India Daily Weather and Air Quality (Kaggle, Open-Meteo / CAMS), CPCB AQI repository. Built with help from Claude and ChatGPT.

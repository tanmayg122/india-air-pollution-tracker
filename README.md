# India Air Pollution Tracker

Pollution types across 50 Indian cities (Aug 2022 to Oct 2026), found with K-means clustering.
Live dashboard: https://tanmayg122.github.io/india-air-pollution-tracker/

Tanmay Gautam, 24151020. DEC 351 Fundamentals of AI/ML.

## Files
- `index.html`: the dashboard (single file, no build step)
- `Tanmay_24151020_Air_Pollution_Types.ipynb`: full analysis notebook
- `colab_air_pollution.py`: same analysis, paste into one Google Colab cell (loads data from this repo)
- `data/`: air quality and weather (Kaggle: India Daily Weather and Air Quality, Open-Meteo / Copernicus CAMS), CPCB hourly AQI (CPCB AQI repository via Vonter/india-cpcb-aqi, ODbL)
- `presentation/`: slides (pptx, pdf)
